OPTIONAL COMPATIBILITY PATCHES - OFFLINE TEAMBUILDER 2.1.7

Only use a patch if you use the matching mod. Pick ONE:

Other mod                       Patch filename starts with
AIO Dynasty 1.4.1                AIO-Dynasty-OfflineTeamBuilder
Playoff Customizer 1.3.0         OfflineTeamBuilder-PlayoffCustomizer
Conference Customizer 1.0.2      OfflineTeamBuilder-ConferenceCustomizer
Dynasty Customizer 1.1.0         OfflineTeamBuilder-DynastyCustomizer

Keep the original mod and OfflineTeamBuilder.fbmod enabled.
Import the matching patch into MMC and give it HIGHER PRIORITY than both.
MMC must show the patch as having the highest precedence.
Disable older compatibility patches for that combination. Restart through MMC.
No additional DLL is needed. Do not enable every patch.

POPUP REMOVER 1.2.0

No extra Popup Remover patch is needed, including with AIO Dynasty.
Its popup fixes load early and survive the normal TeamBuilder/customizer patch.
Use this order, from LOWER to HIGHER precedence:

  Popup Remover -> AIO/customizer and TeamBuilder -> matching compatibility patch

Putting Popup Remover below AIO/the customizer keeps that mod's other menu
changes too. With only Popup Remover and TeamBuilder, put TeamBuilder higher.
Disable the old PopupRemover or combined PopupRemover compatibility patches.
After updating Popup Remover, use MMC's Delete ModData and Launch once, as its
author recommends. These instructions apply to Popup Remover 1.2.0.

Use Dynasty Customizer instead of stacking the standalone Conference and
Playoff Customizers. Do not stack a standalone customizer on AIO with these
patches; those combinations are not covered here.

These patches preserve the selected mod's menu changes, offline TeamBuilder
import and TeamBuilder's hub logo refresh. They do not change the DLL or add
features that the original mods do not support. Remove a patch to undo it.

The patches passed local bytecode and MMC resource-composition checks.
They still need in-game confirmation with your setup.
Editable fbprojects are available in the repository under assets/compatibility.
