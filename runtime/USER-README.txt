OFFLINE TEAMBUILDER 2.1.4
JDHalfRack / Ace / Timberline Tex

Use downloaded TeamBuilder teams in offline Dynasty, with uniforms, stadiums,
logos and custom stadium sounds, without resetting your Dynasty progress.

INSTALL

1. Back up your saves. Close the game and MMC Mod Manager.
2. Copy the DLL from this ZIP's Plugins folder into MMC's Plugins folder.
   Replace the older DLL. Move any OfflineTeamBuilder.dll and
   OfflineTeamBuilderReentry.dll backups OUTSIDE Plugins.
3. Open MMC. Import and enable OfflineTeamBuilder.fbmod. Disable older
   OfflineTB / Offline TeamBuilder fbmods so only this version is enabled.
4. Launch through MMC and keep MMC open. Load your offline Dynasty or create
   one and add your downloaded teams. Give the assets a moment to load.

Install BOTH the DLL and fbmod. No Play Now or practice-mode trick is needed.

OfflineTeamBuilder.fbproject is for editing in MMC Editor 1.1.0.6.
You do NOT need to open it or install it to play.

If assets stop loading, restart the game. For help, share runtime.log and
status.json from MMC\Plugins\OfflineTeamBuilderRuntime. Review logs for personal
paths before posting. Don't delete your team-asset cache while troubleshooting.
A news card may occasionally need you to select another tile and return.
