OFFLINE TEAMBUILDER 2.1.7 - INSTALL

1. Close the game and MMC Mod Manager.
2. Copy Plugins/OfflineTeamBuilderRuntime.dll into MMC/Plugins, replacing the
   old version. Move legacy TeamBuilder DLLs and DLL backups out of Plugins.
3. Import and enable OfflineTeamBuilder.fbmod in MMC. Enable only one version.
   Keep required AIO and compatibility mods enabled for AIO dynasties.
4. Restart MMC, launch the game through MMC, and keep MMC running.
   No F9 step is needed. TeamBuilder teams must already be downloaded.

USING AIO DYNASTY OR A CUSTOMIZER?

Open "compatibility patches" and follow its README. Enable only the patch for
your mod and give it highest precedence. Keep the original mods enabled.
Popup Remover 1.2.0 needs no extra patch; see the included load-order note.
